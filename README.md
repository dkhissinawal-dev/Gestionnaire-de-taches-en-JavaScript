# Gestionnaire-de-tâches-en-JavaScript

Nous avons réaliser une application web permettant de gérer une liste de tâches. 

Le projet a été développé en JavaScript, avec les notions de variables, fonctions, tableaux, objets littéraux, conditions, boucles, événements et manipulation du DOM. 

## Fonctionnalités : 

L’utilisateur doit pouvoir ajouter, consulter, modifier et supprimer des tâches, mais aussi les filtrer et effectuer une recherche. 


## Comment lancer le projet:

L'utilisateur entre dans le formulaire un titre, un statut (obligatoire) et une description facultative. 

Le statut peut être choisi entre :  

* A faire
* En cours
* Terminée
* Bloquée


L'utilisateur clique sur le boutton "Ajouter une tache"

Ensuite la tache (titre, description, statut) apparaît dans la section "Mes tâches" situé en bas de la page.
