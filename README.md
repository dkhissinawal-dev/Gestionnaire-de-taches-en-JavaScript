* Emilie

Nous avons réaliser une application web permettant de gérer une liste de tâches. 

Le projet a été développé en JavaScript, avec les notions de variables, fonctions, tableaux, objets littéraux, conditions, boucles, événements et manipulation du DOM. 

## Fonctionnalités : 

L’utilisateur doit pouvoir ajouter, consulter, modifier et supprimer des tâches, mais aussi les filtrer et effectuer une recherche. 


## Comment lancer le projet:

L'utilisateur entre dans le formulaire un titre, un statut (obligatoire) et une description facultative. 

Le statut peut être choisi entre :  

* A faire
* En cours
* Terminée
* Bloquée


L'utilisateur clique sur le boutton "Ajouter une tache"

Ensuite la tache apparaît dans la section "Mes tâches" situé en bas de la page. Elle contient un titre, une description est un statut. 

### Modification :

Grâce au bouton "modifier" l'utilisateur peut modifier le titre, la description et le statut.


### Suppression : 

Lorsque l'utilisateur clique sur le boutton "supprimer" une alerte apparaît sur l'écran et demande si l'utilisateur est sûr de vouloir supprimer la tâche (choix: "oui" pour la supprimer, "non" sinon).


### Recherche:

L'utilisateur peut rechercher une tache en entrant son titre ou une partie de sa description dans la section "Rechercher et filtrer"

### Filtrer:

L'utilisateur peut filtrer les tâches par rapport à leur statut dans la section "Rechercher et filtrer".
